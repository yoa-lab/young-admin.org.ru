## Узнать версию Nginx

Чтобы узнать только, версию Nginx:

```bash
nginx -v
```

Узнать версию Nginx, версию компилятора и параметры установленной конфигурации.

```bash
nginx -V
```

## Проверка конфигурации

Чтобы проверить правильность синтаксиса конфигурационных файлов:

```bash
nginx -t
```

## Отправка сигналов для запуска, остановки и перезагрузки конфигурации

Перезагрузка конфигурационного файла:

```bash
nginx -s reload
```
